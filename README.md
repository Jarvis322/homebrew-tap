# Homebrew tap

```bash
brew tap Jarvis322/tap
```

| Cask | App |
| --- | --- |
| `sysdata` | [System Data](https://github.com/Jarvis322/macos-sysdata), a menu bar app that shows what is inside macOS "System Data" and deletes it item by item |
| `macwake` | MacWake |

```bash
brew install --cask Jarvis322/tap/sysdata
```
